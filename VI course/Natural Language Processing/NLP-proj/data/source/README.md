# Происхождение данных

Датасеты, создаваемые `scripts/generate_data.py`, являются **синтетическими**. Они не скачиваются из Steam, не содержат персональных данных и не описывают реальные аккаунты. Профили формируются по шаблонам с воспроизводимыми параметрами для проверки конвейера обработки.

Глоссарий основан на вручную составленном наборе общих игровых терминов и определений; записи расширяются контекстными пометками жанров. Это демонстрационный ресурс для разработки и тестирования, а не академически размеченный корпус. Для итоговой оценки качества генерации саммари потребуется отдельно собрать и разметить реалистичную выборку с эталонными описаниями.
