# Лабораторная работа № 1 - Сравнительная таблица терминов

Сравнение терминов — 50 понятий с определениями из четырёх источников и сопоставлением трактовок.

## Описание

Репозиторий содержит сравнительную таблицу терминов, используемых в управлении проектами, бизнес-анализе, разработке программного обеспечения и стандартах ГОСТ. Таблица позволяет сопоставить определения из ведущих профессиональных руководств и стандартов.

## Источники
|Источник |	Область |
| --- | --- |
| PMBOK® Guide, 7-е изд.	 | Управление проектами |
| SWEBOK Guide, V4.0	 | Инженерия программного обеспечения |
| BABOK® Guide, v3	 | Бизнес-анализ |
| ГОСТ Р ИСО/МЭК 12207-2010	 | Процессы жизненного цикла программных средств |
| ГОСТ Р ИСО 21500—2023 | 	Управление проектами, программами и портфелями (справочно) |

## Примечания 

* Формулировки изложены в учебно-сравнительном виде.
* Если стандарт не содержит отдельного определения, это отмечено прямо («Отдельного термина нет»).
* Светло-красная заливка в файле обозначает отсутствие отдельного определения термина в источнике.
