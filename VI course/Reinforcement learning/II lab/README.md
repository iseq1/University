# Лабораторная работа №2 — Исследование задачи принятия решений на марковском процессе

Лабораторная работа по исследованию алгоритмов **Value Iteration** (итерация по ценности) и **Policy Iteration** (итерация по стратегиям) на примере среды FrozenLake из библиотеки Gymnasium.

## Цель работы

Исследовать работу алгоритмов поиска оптимальной стратегии в марковском процессе принятия решений (MDP), сравнить их производительность и определить влияние параметров алгоритмов и конфигурации среды на результаты.

## Используемые технологии

- Python 3
- Gymnasium — моделирование среды FrozenLake
- NumPy — вычисления
- Matplotlib — построение графиков
- Pandas — обработка и сохранение результатов экспериментов

## Реализованные алгоритмы

- **Value Iteration** — поиск оптимальной функции ценности путём итерационного применения уравнения Беллмана.
- **Policy Iteration** — поиск оптимальной стратегии посредством чередования оценки и улучшения политики.

Для оценки результатов используются доля успешных эпизодов, среднее количество шагов, число итераций и время выполнения.

## Проведённые эксперименты

1. **Сравнение алгоритмов:** анализ полученных стратегий, функций ценности и вычислительных затрат.
2. **Исследование коэффициента дисконтирования** \(\gamma\): влияние на сходимость, время выполнения и успешность прохождения.
3. **Исследование точности сходимости** \(\theta\): влияние критерия остановки на количество итераций и вычислительные затраты.
4. **Исследование конфигураций среды:** сравнение карт размером 4×4 и 8×8, а также режимов со скольжением и без него.

Результаты экспериментов сохраняются в CSV-файлах, а графики — в каталоге `results/plots`.


## Результаты

По итогам работы сравниваются:

- найденные оптимальные стратегии;
- скорость сходимости алгоритмов;
- время выполнения и вычислительные затраты;
- успешность прохождения FrozenLake;
- влияние параметров алгоритмов и характеристик среды на полученные результаты.

Экспериментальные данные и графики используются для анализа преимуществ и ограничений каждого алгоритма.
