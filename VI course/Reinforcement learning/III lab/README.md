# Лабораторная работа № 3 — Исследование метода Монте-Карло

Проект исследует методы Monte Carlo Control в среде `FrozenLake-v1` (карта 4×4).

## Реализованные алгоритмы

1. **Greedy Monte Carlo Control + Exploring Starts** — жадное управление с исследованием начальных пар «состояние — действие».
2. **Epsilon-Greedy Monte Carlo Control** — ε-жадная стратегия с постоянным параметром ε.
3. **Off-policy Monte Carlo Control + Weighted Importance Sampling** — равномерная поведенческая стратегия и детерминированная жадная целевая стратегия.

Во всех трёх вариантах оценивается функция качества действий `Q(s, a)` на основе возвратов эпизодов.

Параметры по умолчанию:
- среда: `FrozenLake-v1`;
- карта: `4x4`;
- `is_slippery=True`;
- `gamma=1.0`;
- 10 000 эпизодов обучения;
- 1 000 эпизодов оценки;
- три случайных зерна: 42, 43, 44;
- ε-жадный алгоритм: ε = 0.10 в основном сравнении;
- дополнительный перебор ε: 0.02, 0.05, 0.10, 0.20, 0.30.

Можно переопределить параметры:

```bash
python -m src.main --episodes 20000 --eval-episodes 2000 --seeds 42 43 44 45 46
```

Быстрый тестовый запуск:

```bash
python -m src.main --episodes 1000 --eval-episodes 300 --seeds 42
```

## Серии экспериментов

- Основное сравнение трёх алгоритмов по нескольким случайным зернам.
- Перебор параметра ε для ε-жадного метода.
- Сравнение качества при разных бюджетах обучающих эпизодов.
- График скользящего среднего награды в процессе обучения.
