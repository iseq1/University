# Лабораторная работа №1 — Многорукий бандит

Исследование задачи о многоруком бандите и сравнение различных стратегий выбора действий.

## Цель

Исследовать задачу многорукого бандита, реализовать несколько алгоритмов выбора действий и изучить влияние их параметров и количества доступных действий на эффективность обучения.

## Реализованные алгоритмы

- **Greedy** — выбор действия с максимальной текущей оценкой.
- **Epsilon-Greedy** — баланс исследования и использования с помощью параметра `ε`.
- **UCB (Upper Confidence Bound)** — исследование действий с учётом неопределённости их оценок.
- **Gradient Bandit** — обновление предпочтений действий и выбор через Softmax.

## Метрики

Для оценки алгоритмов используются:

- **Average Reward** — средняя накопленная награда;
- **Optimal Action Rate** — доля выборов оптимального действия.

Каждый эксперимент выполняется в течение `10 000` эпизодов и усредняется по `100` независимым запускам.

## Эксперименты

В работе исследуются:

1. Сравнение четырёх алгоритмов.
2. Влияние параметра `ε` в Epsilon-Greedy.
3. Влияние параметра `c` в UCB.
4. Влияние параметра `α` в Gradient Bandit.
5. Влияние количества рычагов: `3`, `5`, `10` и `20`.

Используемые параметры для эксперимента с количеством рычагов:

```text
Epsilon-Greedy: ε = 0.05
UCB:            c = 1.0
Gradient Bandit: α = 0.1
```

## Основные результаты

При базовой конфигурации среды:

|    Algorithm     | 	Average Reward | 	Optimal Action Rate | 
|:----------------:|:---------------:|:--------------------:|
|     Greedy	      |     0.3817	     |        13.00%        |
| Epsilon-Greedy	  |     0.4114	     |        58.69%        |
|       UCB	       |     0.4369	     |        82.88%        |
| Gradient Bandit	 |     0.4379	     |        82.18%        |

Увеличение количества рычагов приводит к снижению средней награды всех алгоритмов, поскольку увеличивается пространство действий, которое необходимо исследовать.
