# Автоматическое распознавание и сбор статистики с диаграмм

Проект предназначен для автоматизированного распознавания и анализа данных на столбчатых диаграммах, содержащихся в презентациях PowerPoint (`.pptx`).

Система извлекает изображения диаграмм, определяет столбцы и их сегменты, распознаёт текстовые обозначения и рассчитывает процентное соотношение сегментов. Результаты обработки сохраняются в структурированном формате и доступны для дальнейшего анализа.

## Важная ремарка

- Код проекта под NDA, сорри..
- Результат работы зафиксирован в формате итогового отчета

## Возможности

- Загрузка и обработка PowerPoint-презентаций (`.pptx`).
- Извлечение изображений диаграмм из слайдов.
- Обнаружение столбцов и цветовых сегментов.
- Распознавание текстовых значений с использованием OCR.
- Расчёт процентного распределения сегментов на основе геометрических характеристик.
- Использование YOLO для обнаружения объектов (при наличии соответствующей модели).
- Формирование структурированных результатов обработки.
- Визуализация статистики и сравнение результатов.
- Экспорт данных в CSV и Excel.

## Технологии

- **Python** — основной язык разработки.
- **OpenCV** — обработка изображений и компьютерное зрение.
- **YOLO (Ultralytics)** — обнаружение объектов.
- **EasyOCR / Tesseract** — распознавание текста.
- **NumPy, Pandas** — обработка и анализ данных.
- **Matplotlib / Plotly** — визуализация результатов.
- **Streamlit** — пользовательский интерфейс.

## Результаты работы

По завершении обработки пользователь получает:
- сведения о найденных диаграммах и столбцах;
- информацию о цветовых сегментах;
- рассчитанные процентные значения;
- результаты распознавания текстовых обозначений;
- сводную статистику по обработанным презентациям.

Доступен экспорт результатов в форматы CSV и XLSX.
