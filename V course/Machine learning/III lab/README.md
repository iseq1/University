# Лабораторная работа №3 — Реализация RAG-модели

## О проекте - Система RAG для киберспорта Dota 2

Система генерации с дополненной реальностью (RAG) для аналитики киберспорта Dota 2, использующая пользовательский поиск по свежим данным киберспорта из API OpenDota и языковую модель, работающую только с декодером.

Этот проект реализует полный конвейер RAG (генерация с дополненной реальностью) для ответа на вопросы, связанные с профессиональным киберспортом Dota 2.

Система:

* собирает свежие данные киберспорта из API OpenDota,
* создает пользовательскую базу данных для поиска,
* выполняет семантический/контекстный поиск,
* внедряет полученный контекст в запросы,
* генерирует ответы, используя языковую модель, работающую только с декодером.

Проект был разработан в качестве лабораторной работы для курса «Машинное обучение».

## Dataset

Набор данных формируется динамически на основе API OpenDota.

Включенные сущности:
* Профессиональные команды
* Профессиональные игроки
* Профессиональные матчи
* Информация о турнирах
* 
Статистика набора данных:
* ~4600 исходных документов
* ~9000 семантических фрагментов

Актуальность:
* Набор данных генерируется на основе данных API киберспорта в режиме реального времени и, следовательно, содержит информацию, более актуальную, чем дата окончания обучения языковой модели.
